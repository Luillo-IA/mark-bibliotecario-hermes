# Desarrollo de MARK Biblioteca

Responde en español. Este repositorio contiene solo código y ejemplos ficticios.
No añadas cuentas reales, tokens, `.env`, bases de datos, informes de préstamos,
sesiones o respaldos al índice de Git. Revisa el contenido preparado antes de
cada commit; `.gitignore` no protege archivos ya rastreados.

Al cerrar cada cambio relevante, ejecuta las pruebas apropiadas y crea un commit
con un mensaje que describa el resultado. Indica si el commit sigue solo local
o si se publicó en GitHub. No acumules varios objetivos completos sin commits.
No publiques código nuevo sin la autorización correspondiente del propietario.

Las pruebas deben usar datos ficticios. No ejecutes el instalador, tareas reales,
renovaciones ni mensajes de Telegram solo para probar un cambio de código.
Conserva las consultas del chat como lectura local y el trabajo web en las
rutinas deterministas. Nunca confirmes una renovación sin fecha posterior.

Mantén las instrucciones y los límites conocidos del README al día. Las pruebas
de navegador necesitan Chromium; las nativas necesitan un checkout de Hermes.
Informa de las pruebas omitidas y no las presentes como aprobadas.
